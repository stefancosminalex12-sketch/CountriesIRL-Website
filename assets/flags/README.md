# Flag sources

`russian-empire-1914.png` is a 540 × 360 rendering of the 1914–1917
Russian Empire private-use flag, with the imperial eagle in a yellow canton.
Source: [Wikimedia Commons, Flag of Russia (1914-1917).svg](https://commons.wikimedia.org/wiki/File:Flag_of_Russia_(1914-1917).svg),
by Srg36, listed as public domain. The original `russian-empire.svg`
(1858–1883) is retained for potential future use.
